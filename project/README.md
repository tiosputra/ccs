# project/

Source material for the whole project: the product spec, the art brief, launch
readiness, the design handoff. Every task reads it and no task owns it.

- `/plan-prd` and `/plan` read it before writing a PRD or a plan.
- `/idea`, `/market` and `/decide` read it as the project's own statement of what
  it is building.
- A task that changes something here says so in its own `tasks/<date>_<task>/`
  docs. Nothing a task produces is saved here.

The contents stay local — they describe an unreleased product — so this README is
the only tracked file here.
